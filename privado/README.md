# Insumos privados de reproducción

Esta carpeta no contiene datos en la distribución del repositorio. El detalle de cálculo individualizado se conserva fuera de Git.

La exportación de tablas requiere indicar mediante `--entrada` el archivo privado `comparacion_metodologia_original.csv.gz`. Para ejecutar el cálculo completo se necesitan además los insumos congelados inventariados en `00_fuentes/fuentes_y_versiones.csv`, restaurados en `00_fuentes/referencia`, y la caché geográfica en `02_procesamiento`. Estos archivos se excluyen de Git.

No incorporar identificadores de encuestas, coordenadas, originales de consultoras ni credenciales al índice de publicación.
